# 업무 검토 흐름과 PDF 보고서

## 사용자 흐름
상황 보고 확인 → 업무 상황 답변 → 에이전트와 추가 조사 → 다음 행동과 판단 저장 → 보고서 미리보기와 PDF 다운로드.

## 설계
- 업무/실행/발견 그룹별 검토 상태와 사람의 판단을 버전으로 보관한다. 지난 판단과 맥락은 같은 업무·그룹의 후속 조사에 전달하되 검증된 원인으로 단정하지 않는다.
- 업무 상세 안에서 대화를 이어가며 실제 AI/규칙 기반 모드를 구분한다. 실제 AI는 집계와 사용자 답변을 보고 도구를 선택하고 추가 확인을 요청할 수 있다.
- 상황 답변·예상된 변화/중요/해결 판단·다음 회복 확인/담당자 확인 등 후속 계획을 저장한다. 일정이나 임계값을 자동 변경하거나 외부로 전송하지 않는다.
- PDF는 서버가 실행 당시 수치·기간·조회 근거·AI 해석·사용자 의견·다음 행동을 구분해 생성한다. 한글 글꼴을 포함하고 길이에 따라 페이지를 나눈다.
- 준비된 매출 시나리오와 기존 이력은 유지한다. 화면은 중립적인 업무 용어를 쓰며 원본 출처 메타데이터는 보존한다.

## 검증
업무/실행/그룹 격리, 재방문, 버전 충돌, 대화 중 개입, 사람 의견 기억, 근거 일치, 보고서 스냅샷과 한글 PDF 파일을 검증한다. 브라우저에서 전체 흐름과 PDF 다운로드를 확인한다.

검증 결과: 전체 테스트 66개, 실제 PostgreSQL 검증 7개 및 빌드 통과. Chrome에서 5단계 진행·후속 답변·근거·판단·PDF 다운로드·재방문 복구·모바일을 확인했다. 실제 OpenAI와 PostgreSQL로 추가 조회·AI 후속 질문·행동 저장·PDF 생성까지 완료했다. PDF를 이미지로 변환해 한글과 페이지 구성을 확인했다. 검증용 업무와 대화는 정리했다.

실제 AI가 범위를 바꾸거나 같은 조회를 반복하는 경우를 막도록 업무 대화의 범위는 응답 스키마에 고정하고, 아직 실행하지 않은 도구/분석축 조합에서 다음 조회를 선택하도록 했다. 완료 해석에 인용된 근거는 보고서에서 빠지지 않도록 보존한다.
