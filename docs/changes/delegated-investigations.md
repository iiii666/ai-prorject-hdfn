# 맡긴 업무와 후속 조사

## 문제와 목표
조사 대화·저장한 분석·정기 감시·실행 이력 네 메뉴를 사용자 업무 중심으로 통합한다. 조건 평가 후 고정 추가 조회만 하는 기존 감시와, 결과에 따라 도구를 선택하는 자동 조사를 구분한다.

## 설계
- 기본 메뉴는 AI에게 조사하기 / 맡긴 업무. 보관함은 조사 화면의 보조 기능, 활동 기록·설정은 업무 상세에 배치한다.
- 기존 감시는 기본적으로 규칙 점검을 유지한다. 신규 조사에서 맡기는 업무는 원래 조사 모드를 저장하며 실제 AI / 명시적 시연 / 규칙 점검을 선택할 수 있다.
- 서버가 조건 평가 후 최대 3개 발견 그룹의 조사 세션을 순차 실행한다. 세션당 기존 한도(조회 6회, 판단 8회)를 유지하고 결과와 근거를 그대로 보관한다. API 키가 없거나 조사가 실패하면 상태를 명시하며 AI 성공으로 표시하지 않는다.
- 자동 조사에서는 기간·점포·채널 및 상품군/고객 등급 범위를 서버에서 고정한다. 후속 대화는 같은 세션을 열어 진행한다.
- 실행 보고서 JSON에 발견 상태(새로 발견/지속 중/회복/판단 보류), 최초 발견일, 이전 실행 참조, 조사 세션 참조를 보관한다. 같은 설정과 실행 유형끼리 비교하며 시연 재현·시험·정기 실행을 섞지 않는다. 데이터 부족은 회복으로 판정하지 않는다.
- 기존 테이블과 이력을 보존하고 보고서 및 설정에 선택 필드를 추가한다.

## 검증
기존 단위·DB 통합·빌드를 실행한다. 새 검증은 자동 조사 분기와 한도, 범위 이탈 차단, 모델 실패·키 미설정, 발견 지속·회복·데이터 부족·설정 변경 격리, 업무 화면과 후속 대화 연결을 다룬다. 실제 모델 호출과 모델 대역/시연을 구분해 보고한다.
