# 2주 이력과 새 감소 점포 시연

사용자가 지정한 기존 조사 업무를 전체 점포의 발표용 합성 시나리오로 구성한다. 실제 DW 주문·결제 데이터를 수정하지 않고, 별도 분석 앱을 연결하여 원래 저장 분석도 보존한다.

- 과거 2주: 첫 주 전 점포 정상, 둘째 주 판교점만 전주 대비 16% 감소.
- 지금 확인하기: 더현대 서울만 전주 대비 18% 감소. 다른 점포는 증가.
- 기준은 매출 10% 이상 감소이며 실행당 발견 점포는 정확히 하나다.
- 주차 간 현재/비교 금액과 점포→채널·상품군·등급·일별 집계의 합계를 일치시킨다.
- 추가 조사와 후속 대화도 같은 시나리오를 사용하고, 일반 DW 조회·실제 AI 호출과 섞지 않는다.
- 데이터 출처는 설정·보고서 메타데이터에 보존한다. 화면에는 사용자 요청에 따라 중립적인 업무·분석 용어를 사용한다. 과거 보고서는 replay 유형이며 실제 과거 실행으로 표시하지 않는다.
- 반복 준비 시 같은 주차 이력을 추가하지 않는다. 자동 실행은 비활성 상태로 준비한다.

준비 명령: `node scripts/seed-task-presentation.mjs <업무 UUID>`

회귀 검증은 2주 분기/발견 건수/점포 차이/원본 DW 보존/기간 간 금액 연속성/세부 집계 합계/중복 준비 방지/근거와 연결 분석의 동일 데이터 사용을 포함한다.

검증 결과: `npm test` 59개와 빌드 통과. 실제 PostgreSQL에 두 시연 주차를 준비하고 Chrome에서 이력 2건, 지금 확인의 다른 점포 1건, 추가 조사 및 합성 근거 표시를 검증했다. 검증용 현재 실행은 정리하여 발표 전에는 과거 이력만 남긴다.
