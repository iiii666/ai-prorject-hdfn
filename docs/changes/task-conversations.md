# 맡긴 업무 안에서 이어가는 조사 대화

## 목표
발견사항을 확인한 사용자가 다른 탭으로 이동하지 않고 업무 맥락 안에서 추가 질문하고, 에이전트가 선택한 조회와 근거를 확인할 수 있게 한다.

## 설계
- 업무 상세에 상황 요약·다음 확인 질문·추천 질문·대화·근거를 제공한다.
- 대화는 업무/실행/발견 그룹/응답 모드에 연결해 보관한다. 재방문 시 같은 대화를 연다.
- 실제 AI는 기존 도구 선택 루프를 사용하며, 집계 결과와 사용자 답변에 따라 추가 조회 또는 확인 질문을 선택한다. 규칙 기반 모드와 구분한다.
- 발표 데이터도 같은 출처·주차로 조회한다. 실제 AI 대화 선택은 정기 업무의 조사 방식과 독립적으로 허용하며 자동 업무 설정이나 준비된 이력을 변경하지 않는다.
- 새 대화 생성은 서버가 해당 업무의 실행 결과에서 범위와 데이터 출처를 결정한다. 임의 세션이나 다른 업무의 근거를 연결하지 않는다.
- 기존 조회/판단 한도, 버전 검사, 진행 중 개입 및 근거 검증을 유지한다. 사용자 질문은 실제 AI 모드에서 집계와 함께 모델에 전달된다.

## 검증
업무 간 세션 격리, 재방문 복구, 잘못된 실행/그룹 거절, 이전 버전 요청 거절, 발표 데이터 일치, 모드별 분리 및 추가 조사 동작을 검증한다. 브라우저에서는 업무 안에서 질문·응답·근거·재방문을 확인한다.
