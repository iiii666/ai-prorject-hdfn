# AI 조사 범위와 근거 응답 검증 수정

## 문제
점포별 매출을 조사한 뒤 저장 초안을 요청하면 첫 조회는 성공하지만 다음 AI 응답의 점포·종료일 자리표시 값이 검증에 실패했다. 완료·초안 응답에도 사용되지 않는 scope 필드가 필수인데, 이를 새 조회 조건처럼 검증하고 기존 조사 범위를 덮어쓰고 있었다. AI가 다른 범위의 근거 ID를 인용하려는 경우도 실제 호출에서 확인했다.

## 변경
- 점포 응답은 현재 DB의 점포 ID 문자열 또는 전체를 의미하는 빈 문자열만 반환하도록 구조화 응답 스키마를 제한한다.
- 실제 조회(tool)에서만 새 범위를 검증한다. 완료·추가 질문·저장 초안은 이미 검증된 현재 범위를 유지한다.
- 현재 범위에서 인용할 수 있는 근거 ID를 모델 입력과 구조화 응답 enum으로 제공한다. 서버의 기존 근거 검증도 유지한다.
- 기존 숫자 없는 설명 규칙을 구조화 응답의 문자열 패턴에도 적용해, 모델이 작성한 수치는 검증 표로만 확인하도록 유지한다.
- 점포·근거 응답 제약과 잘못된 완료/초안 범위에서도 기존 기간·점포를 유지하는 회귀 검증을 추가한다.

## 검증
`npm test` 57개와 빌드를 통과했다. 실제 PostgreSQL과 실제 AI에서 “매주 점포별 매출 변화를 조사하고, 감소한 곳은 추가로 살펴봐줘. 이 결과를 저장하고 매주 확인해줘.”를 실행해 두 번의 조회 후 저장 초안 생성까지 정상 완료했다. 업무를 자동 저장하거나 활성화하지 않았다.
