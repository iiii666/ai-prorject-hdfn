# 현대백화점 DW

첨부 목업을 바탕으로 만든 React + TypeScript 분석 워크스페이스입니다. VS Code에서 실행할 수 있습니다.

> 프론트엔드 데모입니다. 데이터·파이프라인 상태·AI 인사이트는 예시이며, 실제 현대백화점 DW, 사용자 인증, AI API와 연결되어 있지 않습니다.

## VS Code에서 시작하기

Node.js **22.12 이상**(또는 24 LTS)과 Git을 먼저 설치하세요.

```bash
git clone https://github.com/iiii666/ai-prorject-hdfn.git
cd ai-prorject-hdfn
npm ci
code .
npm run dev
```

브라우저에서 **http://localhost:5173** 에 접속합니다. `code` 명령이 없다면 VS Code의 **파일 → 폴더 열기**로 프로젝트 폴더를 선택하세요. 서버 종료는 터미널에서 `Ctrl+C`입니다.

VS Code의 **터미널 → 작업 실행 → DW 개발 서버**로도 실행할 수 있습니다.

## 구현 화면

| 메뉴            | 기능                                                                               |
| --------------- | ---------------------------------------------------------------------------------- |
| 통합 현황       | KPI, 매출 추이, 캠페인 성과, 예산 요약, 예시 AI 요약                               |
| 고객 분석       | 고객 등급 구성, 신규/재구매/휴면 지표, 세그먼트                                    |
| 매출 분석       | 매출 추이, 상품군 비중, 목표 달성 지표                                             |
| 캠페인 성과     | 성과 테이블, 채널별 목록, 캠페인 상세 팝업                                         |
| 앱 이용 현황    | 활성 사용자 차트, 구매 전환 퍼널                                                   |
| 예산·실적       | 집행률, 잔여 예산, 부문별 예산 비교                                                |
| 데이터 카탈로그 | 자산명·설명·오너 검색, 유형 필터, 리니지 이동                                      |
| 데이터 리니지   | 원천 → 적재 → DW → 마트 → 리포트, 노드 선택, 재귀적 상·하류 조회, 도메인/방향 필터 |
| 관리자 설정     | 브라우저 로컬 설정 저장, 샘플 연결 상태 안내                                       |

- 기간·점포·채널을 선택한 뒤 **조건 적용**을 누르면 조회 조건이 반영됩니다.
- **요약 다운로드**는 현재 조회 조건에 해당하는 통합 KPI CSV를 내보냅니다. Excel용 UTF-8 BOM을 포함합니다.
- 모바일에서는 왼쪽 위 메뉴 버튼을 사용합니다.
- 주소의 `#customers`, `#lineage` 등으로 화면을 직접 열 수 있습니다.
- AI 인사이트와 알림은 설명 팝업이며 실제 모델 호출이나 알림 발송은 없습니다.

## 샘플 데이터 규칙

`src/data.ts`가 샘플 자산, 관계, 캠페인, 시계열 생성과 집계 배율을 제공합니다. 기간·점포·채널에 따라 수량/금액을 예시 배율로 조정하며, 일부 비율은 고정된 시나리오 값입니다. 실제 고객 단위 집계나 실시간 적재가 아닙니다. 리니지 화면의 갱신 시각도 고정 예시입니다.

설정은 현재 브라우저의 `localStorage`에만 저장되며 사용자 계정이나 서버에 저장되지 않습니다.

## 명령어

```bash
npm run dev       # 개발 서버
npm run build     # TypeScript 검사 + 프로덕션 빌드
npm run preview   # dist 빌드 미리보기 (기본 포트 4173)
```

## 폴더 구조

```text
src/
  App.tsx         # 화면, 라우팅, 필터, 카탈로그, 리니지, 팝업
  data.ts         # 샘플 데이터와 데이터 계보 관계
  main.tsx        # React 진입점
  styles.css      # 반응형 스타일, 밝은 분석 / 어두운 리니지 테마
.vscode/          # 실행 작업 및 확장 추천
```

React 19, TypeScript 5, Vite 7, Recharts, Lucide 아이콘을 사용합니다. 웹 폰트를 불러오지 못하면 시스템 글꼴로 표시됩니다.

## 실제 DW 연결 시

별도 백엔드 API에서 데이터 조회와 인증·권한 검증을 처리하고 `src/data.ts`의 예시 데이터 사용 부분을 API 호출로 교체하세요. DW 비밀번호나 API 비밀 키를 브라우저 코드 또는 `VITE_*` 환경 변수에 넣지 마세요. AI 요약은 검증된 집계 데이터와 서버 측 모델 호출을 연결해야 합니다.

현대백화점 공식 서비스가 아닌 개발용 프로토타입입니다.
